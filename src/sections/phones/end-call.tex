\section{Ending Calls}

\subsubsection{To end a call:}

Do one of the following:

\begin{itemize}
	\item If you are using the handset, press the \textbf{Cancel} soft key or
	hang up the handset.
	\item If you are using the headset, press the \textbf{Cancel} soft key.
	\item If you are using the speakerphone, press
		\scalerel*{\includegraphics{images/yealink/btn-speaker.png}}{B} or
		the Cancel soft key.
\end{itemize}

\begin{quote}
	\textbf{Note}
	
	To end a call placed on hold, you can press the \textbf{Cancel} soft key to
	end the call directly, or press the \textbf{Resume} soft key to resume the
	call before ending it.
\end{quote}
